# AF — for foroozan family

UI این پروژه مطابق طراحی خودت بازسازی شد: پس‌زمینه تیره، تگ‌لاین "for foroozan family" بالا، متن سبز "connect" وسط به‌عنوان دکمه، لوگوی AF زیرش، و پایین صفحه پیل "server" با نقطه‌ی رنگی وضعیت (قرمز=قطع، نارنجی=در حال اتصال، سبز=متصل).

پشت صحنه از لایبرری رسمی و متن‌باز Psiphon استفاده می‌کنه (از مخزن Maven خودشون، نیازی به دانلود دستی AAR نیست).

## ساخت APK بدون نصب چیزی (با گیت‌هاب)
۱. فایل‌های این پروژه رو توی یه ریپازیتوری گیت‌هاب آپلود کن (با همین ساختار پوشه‌ها)
۲. تب Actions → روی "Build APK" → Run workflow
۳. بعد از تیک سبز، از بخش Artifacts فایل `MyTunnelApp-debug` رو دانلود کن
۴. زیپ رو باز کن، `app-debug.apk` رو روی گوشی نصب کن

## نکته درباره کانفیگ
فایل `app/src/main/assets/psiphon_config.json` با مقادیر تست عمومی Psiphon پر شده. برای یه نسخه‌ی واقعی/عمومی، بهتره شناسه اختصاصی از خود Psiphon بگیری.
